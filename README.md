### 2. البحث والفرز حسب الأدوية الجنيسة (Génériques & DCI):
- تصفية فورية وسريعة:
  * **جنيس / Générique (GE)**: يمثل **80.4%** من الأدوية المعتمدة (4,362 دواء).
  * **أصلي مرجعي / Princeps - Référence (RE)**: يمثل **17.7%** (958 دواء).
  * **حيوي / Biosimilaire (BIO)**: (58 دواء).
- **محرك البدائل الجنيسة الفوري (Génériques Finder)**:
  * عند النقر على أي دواء، يعرض النظام مباشرة قائمة بجميع الأدوية الجنيسة والبدائل المتاحة بنفس المادة الفعالة (DCI) ونفس العيار والجرعة لمقارنة المخابر والأسعار والمنشأ.
  * تبويب خاص: **دليل البدائل الجنيسة (Guide des Molécules)** يستعرض أشهر المواد الفعالة وبدائلها.

### 3. عرض كافة تفاصيل المنتج الصيدلاني (19 خاصية تقنية):
- الاسم التجاري (Nom de marque)
- التسمية الدولية المشتركة (DCI / Substance active)
- رقم التسجيل (N° d'enregistrement)
- رمز التصنيف الصيدلاني (Code de nomenclature)
- الفئة العلاجية المعتمدة (Classe thérapeutique)
- الشكل الصيدلاني (Forme galénique)
- الجرعة والعيار (Dosage)
- نوع التعليب والتعبئة (Conditionnement)
- القائمة وجدول المواد السامة (Tableau / Liste I, Liste II, Stupéfiants)
- قناة الصرف (Hôpital HOP / Officine OFF)
- المنشأ وتوطين التصنيع (إنتاج محلي جزائري 🇩🇿 مقابل استيراد 🌐)
- اسم المخبر صاحب القرار (Laboratoire détenteur)
- بلد المخبر (Pays d'origine)
- تاريخ التسجيل الأولي والنهائي (Date initiale & finale)
- مدة الصلاحية والاستقرار (Durée de stabilité)
- الملاحظات (Observations)
- إمكانية طباعة البطاقة التقنية لكل دواء بضغطة زر (Imprimer la fiche technique).
